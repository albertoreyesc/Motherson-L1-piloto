# Evidencias de integración

Resultados fechados de instalación, SQL, autorización, persistencia y publicación. Se conservan porque la documentación técnica los cita; no representan el estado actual de los saldos ni garantizan que una licencia o red siga igual.

- `administracion-v2/`: comprobaciones de administración de líneas y capturas locales controladas.
- `publicacion-2026-11-22/`: evidencia de esa publicación.
- JSON de Azure/Render: resultados del entorno y fecha indicados en cada archivo.

Las nuevas comprobaciones de organización están en el [inventario del repositorio](../ORGANIZACION_REPOSITORIO.md). No se reejecutaron instalaciones ni cargas para reorganizar archivos.
