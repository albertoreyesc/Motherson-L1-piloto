# Archivo documental

Antecedentes de diseño, migraciones, pruebas y demostraciones previas a la entrega v3. Se conservan por trazabilidad y para interpretar los datos y herramientas heredados. **No son instrucciones vigentes de arranque o reinstalación.**

Empieza por el [índice actual](../README.md), el [manual de usuario](../MANUAL_DE_USUARIO.md) o el [manual de instalación](../MANUAL_DE_INSTALACION.md).

Las rutas personales, puertos y cantidades de estas notas pertenecen a sus entornos originales. No ejecutar comandos históricos sobre el piloto compartido. La relación completa de documentos movidos está en el [inventario](../ORGANIZACION_REPOSITORIO.md).

Los 50 módulos sustituidos que antes ocupaban `archivo-codigo/` se recuperan desde [el árbol anterior a esta organización](https://github.com/albertoreyesc/Motherson-L1-piloto/tree/8c25f64/archivo-codigo). Estaban fuera de las fuentes de compilación y no se duplican en una segunda carpeta histórica.
