# Evidencias históricas del portal

Capturas y resultados de versiones locales anteriores, organizados por catálogo, puestos, simplificación, continuación e histórico. No son fuentes de inventario ni el manual visual vigente. Las fechas y cantidades corresponden a sus respectivos entornos.

Se conserva esta ruta porque las pruebas y scripts de auditoría escriben o consultan aquí. Reubicarla implicaría cambiar esos consumidores. Los resultados nuevos de runners y compilaciones se ignoran cuando son temporales; una evidencia útil debe revisarse antes de versionarse.

Consulta el [manual de usuario actual](../../documentacion/MANUAL_DE_USUARIO.md) y las [evidencias de integración posteriores](../../documentacion/evidencia-integracion/README.md). No publicar archivos privados o credenciales junto con capturas.
