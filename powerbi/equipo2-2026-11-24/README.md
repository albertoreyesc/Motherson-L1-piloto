# Entrega del equipo 2 incorporada al piloto

[Integración, actualización, límites y recuperación](../../documentacion/INTEGRACION_EQUIPO2_2026-11-24.md).

- `Motherson.pbix`, `modelo_equipo2_original.tmdl` y los README originales conservan la entrega recibida como referencia. No publicar estos originales sobre el piloto ni ejecutar su carga inicial.
- `report/`: definición PBIR adaptada y publicada, con el mismo informe y modelo v2.
- `../administracion-v2/definition/`: modelo activo con claves estables, vistas compartidas y metadatos actuales del catálogo.

Los originales aportan tres páginas de Power BI. El portal también ofrece tres hojas de KPIs y Excel con el mismo alcance de consulta. El panel operativo del portal consulta cada 30 segundos; el informe Power BI depende del refresco del modelo.
